# CLAUDE.md

Инструкции для работы Claude в этом репозитории. Читать перед любой задачей.

## Проект

Промо-сайт студии. Одностраничный скролл-сторителлинг по концепции «бесконечная лента пути»: сцены сменяют друг друга по мере прокрутки.

## Стек

Next.js App Router, React, TypeScript, React Three Fiber, Lenis, Biome, pnpm. Деплой — GitHub Pages.

## Команды

- `pnpm dev` — локальная разработка.
- `pnpm build` — продакшн-сборка.
- `pnpm lint` — проверка Biome.
- `pnpm format` — автоформат Biome.
- `pnpm typecheck` — `tsc --noEmit`.

## Конвенции

Сцены лежат в `components/scenes/<Scene>/`, внешний API — через `index.ts`. Утилиты — в `lib/`.

## Принципы работы

### 1. Думай до кода

Если требование допускает два варианта реализации — спросить, какой нужен, а не выбрать молча. Если видишь более простой путь — предложить его.

### 2. Простота вперёд

Минимум кода под задачу. Никаких абстракций «на будущее», никакой конфигурируемости, которую не просили. Если вышло 200 строк, а можно 50 — переписать.

### 3. Хирургические правки

Менять только то, что относится к запросу. Не переформатировать соседний код. Не «улучшать» стиль. Не трогать другие сцены при правке одной. Не удалять код, не связанный с текущей задачей.

Тест: каждая изменённая строка должна прямо следовать из запроса пользователя.

### 4. Цель → проверка

Для нетривиальных задач — короткий план с критерием проверки на каждом шаге. UI-изменения подтверждаются глазами в браузере через `pnpm dev`, а не «типы прошли».

## Доменные правила

- **Awwwards-планка.** Перед тем как считать задачу готовой — спросить себя: «это похоже на работу студии-победителя?». Если нет — переделать.
- **Скролл — один источник правды.** Прогресс берём из Lenis-провайдера, не запускаем параллельные `requestAnimationFrame` циклы.
- **Производительность.** Перед мерджем R3F-сцены — прогон на low-tier через `detect-gpu` и проверка мобильного фоллбэка.

## Стиль общения

- Простой русский, без англицизмов и тех-сленга в основном тексте. Термины кода и API оставляем как есть.
- Работаем инкрементально, обсуждая каждый шаг. Не «всё одним скопом».
- Большие исследования и тексты выносим в Agent-сабагент, чтобы не раздувать основной чат.
